Desktop

Terminal

Features

Everything you expect. Nothing in between.

ManyDesk follows the workflow people already know from AnyDesk — a 9-digit address, an accept button — and adds what a serverless design makes possible.

Built for speed

Hardware H.264, a dedicated stream per frame and adaptive quality. An idle screen costs almost no bandwidth.

Unattended access

Password with optional TOTP two-factor and trusted devices. On Windows, reachable even at the sign-in screen.

Real clipboard

Text, rich text, images, files and folders in both directions. Copy files here, paste them over there.

Local network

Finds computers on your LAN, connects without internet, accepts a plain IP and wakes machines with Wake-on-LAN.

Voice, camera, chat

Talk while you work, see each other on camera, and keep a chat in every session.

Display control

Switch monitors, change the remote resolution, or add a virtual display to a Mac with no monitor.

Up to 5 viewers

Each with their own permissions, chat and a color-coded pointer that only the host sees.

Power tools

Ctrl+Alt+Del, remote restart with reconnect, privacy mode, whiteboard, switch sides and TCP tunnels.

How it works

Two computers, one direct line

There is no ManyDesk server to sign in to, to pay for or to trust. Computers meet through public networks that already exist, then talk directly.

Rendezvous

A signed, encrypted request of a few kilobytes travels over 11 Nostr relays, 4 MQTT brokers and your local network at once. Any one of them is enough.

Direct connection

Both sides open a direct UDP path through their routers and run QUIC with TLS 1.3 over it. Where no direct path exists, a TURN relay carries the encrypted traffic.

Streaming

The screen is encoded in hardware. Every frame has its own stream, so a lost packet delays one frame, never the ones behind it.

Security

Private by design

Without a server in the middle, there is nobody else who could look in. ManyDesk makes sure of the rest.

  • End-to-end encryptionTLS 1.3 with certificates pinned in both directions for every session.
  • Passwords never travelUnattended access is proven with an HMAC over a fresh challenge; the host keeps only a PBKDF2 key.
  • Least privilegeControl, clipboard, files, audio, camera, terminal: each a separate permission, granted per viewer and revocable at any time.
  • Verifiable buildsOpen source under Apache-2.0. Every release ships with checksums and signed build provenance.
